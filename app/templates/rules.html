So legst du die Regel in Paperless an

  1. In Paperless Workflows öffnen → Workflow hinzufügen, Name z.B. „Companion: {{ p.correspondent }}“.
  2. Auslöser: „Dokument hinzugefügt“, Filter Hat Korrespondent = „{{ p.correspondent }}“.
  3. Aktion: „Zuweisung“ → {% if p.tags %}Tags: {{ p.tags|join(', ') }}{% endif %}{% if p.tags and p.document_type %}, {% endif %} {% if p.document_type %}Dokumenttyp: {{ p.document_type }}{% endif %}.
  4. Speichern, dann hier „In Paperless angelegt“ klicken.
